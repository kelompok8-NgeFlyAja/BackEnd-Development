## Installations and Setup

1. Clone this repository

```bash
  git clone https://github.com/kelompok8-NgeFlyAja/BackEnd-Development.git
```

2. Navigate to project directory

```bash
cd BackEnd-Development
```

3. Install dependencies

```bash
npm install
```

4. Setup Environment Variables make file name .env in project directory like file .env.example.
5. Run the server

```bash
npm run start-dev
```

6. For Run the testing

```bash
npm run test
```
